# OMNII Conformance Contract — BKLIT UI

Status: CONFORMING PRESENTATION SURFACE
Common Layer: OMNII Common Layer v1.0.0
Architectural class: presentation/UI

BKLIT UI is presentation only. It consumes canonical product data and common capabilities and must not create alternate identity, authority, graph, value, ledger or workflow semantics.

The interface may expose Identity, Relationship, Intent, Capability, Discovery, Matching, Context, Availability, Property, Value, Exchange, Workflow, Evidence and Management views. Consequential actions must route to the canonical OMNII runtime and authority checks.

Local visual state is not canonical truth. Atlas is the governed public representation; ACTUAL/runtime state remains authoritative for operational projections.
